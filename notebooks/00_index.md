# Applied Machine Learning for CEE — Notebook Index

Companion notebooks for the lecture decks in `../lectures/` (PowerPoint), one per lecture of
the CEE 4XX design in `../../course/`. Some material is inspired by Derek Hoiem's *CS 441 —
Applied Machine Learning* (University of Illinois Urbana-Champaign, Fall 2026). Each notebook
uses its deck's examples, splits, and seeds, so the numbers match. Each lecture is a Marimo
notebook (`.py`); Jupyter exports live in `../ipynb/`.

**Primary textbook reference:** Forsyth, *Applied Machine Learning*, Springer 2019.

## Lecture map

Every lecture follows the lesson arc in `../lectures/README.md` (sections 0–7: warm-up, question
and attempt, one picture, derive, build and verify, break it, decide, check yourself).
